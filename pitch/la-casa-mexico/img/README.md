# Imágenes de este pitch — La Casa México

Todo lo visual de este pitch específico vive en esta carpeta. Para actualizarlo,
solo reemplaza el archivo respetando el mismo nombre — no hay que tocar el HTML.

## Archivos que puedes agregar/reemplazar aquí

- `hero.jpg` — foto de portada, a pantalla completa detrás del título
  ("ESTRATEGIA DE CRECIMIENTO"). Recomendado: la vista al Zócalo desde una
  suite, formato horizontal, mínimo 1800px de ancho. Si no la agregas, la
  portada se queda solo con el fondo de color de marca (no se rompe nada).

- `suite.jpg` — foto usada en la sección "02 — El reto", junto a las
  estadísticas. Recomendado: foto vertical (proporción 4:5) del interior de
  una suite. Si no existe, se muestra un patrón generativo de respaldo.

- `speakeasy.jpg` — foto de fondo a pantalla completa de la sección
  "05 — La idea" (el concepto speakeasy: la puerta/joyería que revela el
  Zócalo). El texto siempre vive del lado izquierdo con un degradado oscuro
  encima, así que cualquier foto funciona — pero para que se vea mejor,
  usa una imagen donde el lado izquierdo tenga zonas más oscuras/sólidas
  (pared, sombra) y el elemento interesante (la puerta, la vista) esté más
  hacia el centro-derecha. Formato horizontal, mínimo 1800px de ancho.

- `detail.jpg` — foto de detalle opcional, no conectada todavía a ninguna
  sección específica: agrégala aquí si quieres usarla en el futuro en algún
  bloque adicional.

## Reglas rápidas
- Nombres de archivo exactos, en minúsculas.
- JPG o WEBP, ya optimizados en peso (idealmente <400kb cada una).
- Si el archivo no existe, la sección no se rompe: usa su respaldo visual.

## Cómo armar el SIGUIENTE pitch (para otro cliente)

1. Duplica toda la carpeta `pitch/la-casa-mexico/` y renómbrala, por ejemplo
   `pitch/nombre-del-cliente/`.
2. Dentro de esa copia, reemplaza las fotos en `img/` (mismos nombres:
   `hero.jpg`, `suite.jpg`, etc.).
3. Abre el `index.html` de la copia y edita el texto de cada sección — el
   diseño, las animaciones y los colores se actualizan solos porque toda esa
   parte vive en `assets/css/pitch.css` y `assets/js/pitch.js`, compartidos
   entre todos los pitches.
4. Listo — es un link nuevo e independiente que puedes mandar sin que se vea
   el menú ni el resto del sitio.
