# /assets/images/og

Pon aquí `share.jpg` (1200×630px) — la imagen que se muestra al compartir el
link del sitio en redes o WhatsApp.

Nota: por ahora esta imagen no está conectada en el <head> del index.html.
Si la agregas, pide que se añada esta línea dentro de <head>:
<meta property="og:image" content="assets/images/og/share.jpg">
